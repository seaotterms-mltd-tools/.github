# SeaotterMS MLTD Tools

A collection of tools for The Idolmaster Million Live! Theater Days (MLTD), led by **SeaotterMS**.

- [mltd-assetgo](https://github.com/seaotterms-mltd-tools/mltd-assetgo): Asset downloader written in Go.
- [mltd-asset-download](https://github.com/seaotterms-mltd-tools/mltd-asset-download): Asset downloader written in Python.
- [mltd-Image-downloader](https://github.com/seaotterms-mltd-tools/mltd-Image-downloader): Image downloader.
- [mltd-linebot-border-go](https://github.com/seaotterms-mltd-tools/mltd-linebot-border-go): LINE bot for checking event rankings.
- [MinaseIori](https://github.com/seaotterms-mltd-tools/MinaseIori) and [mltd-linebot-border](https://github.com/seaotterms-mltd-tools/mltd-linebot-border): Earlier, unmaintained ranking bots.
